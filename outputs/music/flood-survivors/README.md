# Flood Survivors — Stone Remembers

Accepted by Drew on October 26, 2026. Preserve this recording while revising the
Queen's separate theme.

First listening draft, October 26, 2026. Area/exploration base for the Atlantean
Flood Survivors: refuges, submerged causeways, communal survival, and a way toward
the surface. An original fictional musical identity, not a historical reconstruction.

32 bars of 6/8 at quarter-note 69 BPM, 83.47825 seconds. A soft compound-meter
sway distinguishes it from Closed City's machine pulse. Plucked harp-like chip
arpeggios, a warm reed melody, tuned-stone and skin percussion, rounded bass,
and slow harmonic swells suggest water and old stone without a recorded surf
track or continuous noise bed. Dorian B-natural gives the minor center some hope.
The D–A–G–E tide motif connects this area with the Queen's theme.

The first half opens the path; approximately 0:42–1:03 retreats into a quieter
refuge, before the melody returns. Lo-fi color comes from soft saturation,
restrained upper frequencies and fine quantization, not extra hiss.

- `flood-survivors-stone-remembers-v1.wav`: intended stereo mix, 32 kHz/16-bit.
- Matching `.mid`: seven instrumental/percussion tracks plus tempo/meter track.
  General MIDI playback approximates the custom synth palette.
- `render-info-v1.json`: numerical measurements.
- Rebuild from repository root: `python tools/compose_flood_survivors_music.py --track area`.
  Requires numpy. The source renders in chunks with temporary file-backed buffers.

Installed at the same filename under `game/assets/music/`, mapped as the Flood
Survivors area base. The starting leader's specific music takes priority. The
current game has no single-player exploration scene yet. This area theme is
accepted; the Queen's revised song is reviewed separately.
