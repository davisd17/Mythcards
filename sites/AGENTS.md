# MythCards Websites

Before creating or editing any MythCards web page, read
`../docs/MYTHCARDS_WEB_STYLE_GUIDE.md` relative to this directory. Reuse shared
tokens and established components; preserve approved names, artwork and lore.
Keep the game/universe primary, with tarot supporting it.

Each hosted Site may have its own nested Git repository. Inspect that Site's
README, STYLE_GUIDE.md and .openai/hosting.json before editing or publishing.
Never stage an embedded Site as a gitlink in the parent MythCards repository.
Preserve the selected Site ID and access policy. Report failed checks and
publishing permission blocks; do not bypass security controls.
