# MythCards Website Design

Read STYLE_GUIDE.md before all design/content changes. Use
dist/mythcards-tokens.css for shared foundations. The guide is the standalone
mirror of the parent project's docs/MYTHCARDS_WEB_STYLE_GUIDE.md; update both
together when both are available. Do not assume legacy CSS is fully compliant.

Keep MythCards game/universe first. Approved deck title: Dreams of the North;
subtitle: A MythCards Tarot. Do not rename canonical lore/card identifiers.
No purchases, preorders, signups or release promises without new approval.

This directory is its own Git repository. Reuse .openai/hosting.json's Site ID,
preserve private access, run npm test and JavaScript syntax checks, and report
browser QA separately. Never put Site credentials in files, commands or output.
