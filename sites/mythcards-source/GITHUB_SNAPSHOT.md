# Website Source Snapshot

Snapshot of the current local `sites/mythcards` project for the MythCards GitHub
repository, 2026-10-24. That working directory owns a separate Sites Git repository
and is intentionally excluded from the parent repository. Never add it as a gitlink.

This snapshot includes the complete static `dist`, source preparation and serving
scripts, tests, package metadata, README, agent instructions and style guide.
Private hosting metadata, nested Git history, deployment archives and local QA
captures are intentionally excluded. No publishing or audience changes occurred.

The working website remains in `sites/mythcards`; update this snapshot when backing
up subsequent website changes to GitHub. Do not publish directly from this copy
without first resolving the original Site identity and permissions. The gameplay
screenshot still uses the enlarged low-resolution prototype crop, pending fresh
high-resolution user captures.
